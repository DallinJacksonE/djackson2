## Tech Stack

- **Odin:** Learning Odin to get better at low level programming.
- **Raylib:** A time-tested graphics library that let me not worry about building a game engine.

## Architecture

I learned a lot from this project. I sat down and coded most of it by hand with the Odin docs pulled up. It was fun to think about cameras and physics and how the game all went together to make a fun playing experience. The game runs in a Raylib window for-loop that updates logic, handles physics, and then draws the game. To clean it up I used CLI-AI tools (Hermes Agent Harness) to help me see how I could improve some structure. Feel free to clone the repo, there is a linux executable in the repo that will let you play it if you don't want to compile it yourself.
